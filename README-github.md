# 다섯 사람의 눈 (Five Eyes) 🔍

> 고등학교 「통합사회」 Ⅱ-2 **자유주의와 공동체주의 정의관** 학습을 위한
> 대화형 AI 튜터 + 학습분석 대시보드

학생이 AI를 **가르치면서** 배우는 소크라테스식 튜터입니다.
AI 튜터 '통크'(**통**합사회 소크라**테스**)는 정답을 알려주지 않고 계속 되묻습니다.
교사는 학생들의 학습 과정 데이터를 보고 다음 수업에서 누구에게 어떤 도움을
주면 좋을지 확인할 수 있습니다.

---

## 무엇을 하는 앱인가요

### 🙋 학생 화면 — 3단계 활동

| 단계 | 활동 | 학습 목표 |
|---|---|---|
| **1단계** | 현실 사례를 읽고 롤스·노직·매킨타이어·샌델·왈처 중 **누구의 눈으로 볼지** 골라 자기 말로 설명 | 사상가별 핵심 개념을 사례에 적용 |
| **2단계** | 두 정의관이 충돌하는 쟁점을 **난이도(🔥)를 보고 직접 선택**해 양쪽 입장을 각각 서술 | 대립하는 관점의 동시 파악 |
| **3단계** | 분배에 관한 **자신의 기준**을 근거와 함께 정리 | 정답 없는 문제에 대한 자기 입장 정립 |

학생이 개념어를 몰라도 됩니다. 자기 말로 설명하면 **통크가 핵심 개념어를 얹어
되짚어 줍니다.** "아, 그게 롤스의 '무지의 베일'이네요"처럼요.

### 📋 교사 화면 — 학습 과정 데이터

결과 점수만이 아니라 **어디서 막혔는지**를 봅니다.

- 🚨 **개입이 필요한 학생**이 항상 맨 위로 정렬
- 📊 **문장 예시 의존도 변화 그래프** — 도움 없이 스스로 설명하기 시작했는지
- 🧠 **사상가별 인지 부하 히트맵** — 어떤 개념에서 오래 헤맸는지
- 🧭 **학급 병목** — 다음 차시에 다시 다뤄야 할 개념

각 알림은 **[무슨 일이] [근거 수치] [무엇을 할지]** 세 줄로 제공됩니다.

> 🔴 **인지적 과부하 의심**
> 📉 힌트 3회 전부 소진 + 최장 6분 동안 입력을 시작하지 못함
> **처방** 노직 개념을 오프라인에서 먼저 재설명한 뒤, 같은 사례를 다시 적용해 보게 하세요.

## 설계의 바탕이 된 이론

| 이론 | 시스템에 반영된 방식 |
|---|---|
| **프로테제 효과** (Chase et al., 2009) | AI가 배우는 쪽, 학생이 가르치는 쪽. 통크의 첫 대사가 "저도 알려주세요"라는 부탁 |
| **구성주의 · 인지적 불평형** (Piaget, 1977) | 정답 대신 반례를 던져 스스로 오류를 발견하게 함 |
| **ZPD · 스캐폴딩** (Vygotsky, 1978; Wood et al., 1976) | 문장 완성형 예시 제공 + **점진적 소거** 추적 |
| **ICAP 프레임워크** (Chi & Wylie, 2014) | 예시 의존 감소를 수동적 → 상호작용적 단계 도약의 지표로 사용 |
| **인지부하 이론** (Sweller, 1988) | AI 응답 3문장 제한, A/B 선택지, 질문 부분만 색상 강조 |

## 기술 구조

```
학생 브라우저
  App.jsx ──행동 통지──▶ analytics.js (LearningTracker)
                            ├ 미시 로그 수집 (턴/번복/지연/스캐폴딩)
                            ├ 지표 집계 + 알림 판정
                            └ 배치 전송 (실패 시 재시도)
       │                                    │
       │ POST /.netlify/functions/          │ POST
       │        ask-tongkeu                 ▼
       ▼                            Google Apps Script
  Claude API                              │
  (키는 Netlify 환경변수)                   ▼
                                    Google Sheets
                              [응답][결과][행동로그][학습분석]
```

**API 키는 브라우저로 내려오지 않습니다.** Netlify 서버리스 함수가 대신
호출하고, 키는 환경변수에만 존재합니다.

## 설치 및 실행

### 1. 내려받기

```bash
git clone https://github.com/<사용자명>/five-eyes.git
cd five-eyes
npm install
```

### 2. 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열어 구글 Apps Script 웹앱 주소를 넣습니다.
(시트 연결 없이 학습 활동만 시험해 볼 거라면 비워 두어도 됩니다.)

### 3. 로컬 실행

```bash
npx netlify dev     # 서버리스 함수까지 함께 띄웁니다
```

`ANTHROPIC_API_KEY` 를 로컬 환경변수로 지정해야 통크가 응답합니다.

## 구글 시트 연결

1. 구글 스프레드시트를 새로 만듭니다
2. **확장 프로그램 → Apps Script** 를 열고 `google-apps-script.gs` 내용을 붙여넣습니다
3. **⚠️ `TEACHER_KEY` 값을 본인만 아는 코드로 바꿉니다**
   (기본 placeholder를 그대로 두면 누구나 교사 화면에 들어옵니다)
4. **배포 → 새 배포 → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 이걸로 하지 않으면 연결에 실패합니다
5. 나온 `.../exec` 주소를 `.env` 의 `VITE_SHEET_ENDPOINT` 에 넣습니다

시트 4개가 자동으로 생성됩니다.

| 시트 | 내용 |
|---|---|
| `응답` | 학생의 설명과 통크의 답변 (턴 단위) |
| `결과` | 활동을 마친 학생별 최종 결과 + 세특 문구 |
| `행동로그` | 초 단위 미시 행동 원자료 |
| `학습분석` | 세션별 집계 지표 + 알림 판정 결과 |

## Netlify 배포

1. 이 저장소를 GitHub에 올립니다
2. Netlify → **Add new site → Import an existing project** → 저장소 선택
3. 빌드 설정은 `netlify.toml` 에 있어 자동으로 채워집니다
4. **Site configuration → Environment variables** 에 두 개를 등록합니다

   | Key | Value |
   |---|---|
   | `ANTHROPIC_API_KEY` | `sk-ant-...` ([console.anthropic.com](https://console.anthropic.com)에서 발급) |
   | `VITE_SHEET_ENDPOINT` | Apps Script `.../exec` 주소 |

5. **Deploys → Trigger deploy** 로 다시 배포하면 환경변수가 반영됩니다

## 다른 단원에 적용하려면

`src/App.jsx` 상단의 세 상수만 바꾸면 다른 주제로도 쓸 수 있습니다.

| 상수 | 역할 |
|---|---|
| `THINKERS` | 다룰 사상가와 각자의 핵심 개념 목록 |
| `CASES` | 제시할 현실 사례 (각 사례에 적용 가능한 사상가 지정) |
| `CONFLICTS` | 2단계 충돌 쟁점과 난이도 |

`SYSTEM_PROMPT` 의 `[다루는 범위]` 항목도 함께 수정해야 통크가 범위를 벗어나지
않습니다.

## 개인정보 관련 유의사항

- `행동로그`·`학습분석` 시트에는 **학번과 이름**이 저장됩니다
- 스프레드시트 공유 범위를 **교사 계정으로 한정**해 주세요
- 활동 시작 화면에서 수집 항목을 학생에게 안내하는 것을 권장합니다
- 학생용 학급 대시보드(`우리 반 생각 지도`)는 개인이 특정되지 않도록
  **5명 미만이면 비율을 표시하지 않습니다**
